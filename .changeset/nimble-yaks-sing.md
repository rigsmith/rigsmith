clauderig: new `clauderig desktop share` links a Desktop profile's Claude Code session history to one shared tree, so a session started in any profile's window appears in all of them — and, because the shared tree is the default Desktop root that `clauderig sync` already watches, profile history starts being backed up too (previously it was not synced at all). Safe by construction: the session trees are already partitioned by account uuid, so profiles signed into different accounts write to different subdirectories. Existing history is migrated first and migration never overwrites a file already in the shared tree (enforced with O_EXCL). Refuses while the profile's window is open — Electron keeps writing through a directory handle it opened before the swap — and refuses on an unknown state rather than moving history on a guess. `unshare` is non-destructive: the shared history stays. `--cowork` extends both to the much larger agent-mode tree; `--all` applies to every profile. Directory symlink on macOS/Linux, junction on Windows (no privilege needed). Shown in `desktop list`, in `--json` as `sharedHistory`, and toggled with `s` in the interactive screen.
